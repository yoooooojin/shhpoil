# 라벨링 기준 (송유진 · 김서형 공통)

`tools/collect_comments.py`로 만든 CSV에서 **`type`과 `event_episode` 두 칸만** 채웁니다. `note`는 선택입니다.
`is_spoiler`는 비워 둡니다. 스포인지는 본 회차마다 답이 달라서 `event_episode`로 자동 계산합니다.

| 칸 | 넣을 것 |
|---|---|
| `type` | `결과 공개` / `유출 주장` / `루머·추측` / `감상·출연자 이야기` / `무관` 중 하나 (글자 그대로) |
| `event_episode` | **이 글을 읽으면 알게 되는 가장 늦은 회차의 사건.** 숫자 하나. 결과가 안 드러나면 빈칸 |
| `note` | 무슨 사건인지 짧게 (예: `김도윤 1R 탈락`, `최강록 우승 (돌려 말함)`) |

## 글 종류

1. **결과 공개**: 방송에서 실제로 일어난 결과·전개를 사실로 말함. **돌려 말해도 결과를 알 수 있으면 여기.**
2. **유출 주장**: 공개 전에 녹화장·관계자·유출을 근거로 결과를 안다고 함.
3. **루머·추측**: 짐작이나 소문 ("~설", "~래", "~할 듯").
4. **감상·출연자 이야기**: 출연자·요리·분위기 감상, 응원. 결과는 안 드러남.
5. **무관**: 방송 내용과 관계없음 (영상 품질, 광고, 채널 칭찬).

## 회차 적는 법

- **결과 공개**: 그 결과가 나온 회차. 방영이 끝난 뒤에 쓴 글이어도 **내용의** 회차 (11월에 쓴 "1라운드 탈락 아쉽다" → 3).
- **유출 / 루머**: **실제로 맞았으면** 그 결과의 회차, **틀렸거나 확인 불가면 빈칸.** 맞은 루머도 읽는 사람에겐 결과를 알려 주므로 스포.
- 여러 사건이면 **가장 늦은 회차**.
- 정확한 회차를 모르면 그 회차가 들어 있는 **공개 묶음의 마지막 회차**를 적음. 흑백요리사2 공개 묶음: 1~3 / 4~7 / 8~10 / 11~12 / 13. 그래도 모르면 `note`에 `?`.
- 출연자 이름만 나오고 결과가 없으면 빈칸. 키워드 방식이 이런 글을 잘못 가리는 걸 보여 주는 예시가 됨.
- **기억장 보고 라벨링하지 않기.** 기억장이 틀리면 정답지도 같이 틀려서 점수가 부풀어요.

## 애매한 예

| 글 | type | event_episode |
|---|---|---|
| "1라운드에서 그분 떨어진 거 충격" (12/16 작성) | 결과 공개 | 3 |
| "그 셰프 결국 그 장면에서... 직접 봐" (팀전 결과 암시) | 결과 공개 | 7 |
| "손 셰프 우승설 돌던데 진짜임?" (실제로 아님) | 루머·추측 | 빈칸 |
| "지인이 스태프였는데 결승은 의외의 조합이래" (맞았음) | 유출 주장 | 12 |
| "마지막 소감 듣다가 울었다 ㅠㅠ" (우승 소감 암시) | 결과 공개 | 13 |
| "최강록 셰프 말투 웃김" | 감상·출연자 이야기 | 빈칸 |
| "이 채널 리뷰 깔끔해요" | 무관 | 빈칸 |

헷갈리면: **"아직 그 회차를 안 본 내가 이 글을 읽으면 기분 나쁜가?"** 그렇다면 회차를 적습니다.

## 순서

1. 댓글 모으기 (방영 기간 영상 위주, 작성 시점 분포가 3·7·10·12·13에 고르게 퍼지게)
   ```bash
   export YT_API_KEY="키"        # Windows PowerShell: $env:YT_API_KEY="키"
   python3 tools/collect_comments.py "영상주소1" "영상주소2" --max 60 --out data/raw/A.csv
   ```
   영상을 반씩 나눠 각자 자기 몫을 모으면 따로 나눌 필요가 없어요. `data/raw/`, `data/labeled/`는 레포에 안 올라갑니다.
2. **기준 맞추기**: 같은 댓글 20개를 둘이 따로 달고 `python3 eval/agreement.py data/labeled/calib_A.csv data/labeled/calib_B.csv`. 성격 일치 70% 미만이면 기준부터 다시 이야기하기.
3. `tools/label_tool.html`을 브라우저로 열기 → CSV 열기 → (선택) 공개 일정 열기는 건너뛰어도 됨 (`written_after_episode` 칸이 이미 있음)
   - `1~5` 종류 → 회차 숫자 → `Enter`. 감상/무관은 숫자 키 한 번이면 다음 글로
   - 끝나면 **CSV 저장** → `data/labeled/`에 두기. 원래 열 구조가 그대로 유지되고 `labeler` 열만 붙음
4. 목표: 둘이 합쳐 **300개 이상**, 스포(`event_episode` 있음)가 30% 넘게
