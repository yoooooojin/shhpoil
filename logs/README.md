# 에이전트 실행 로그

쉿스포가 실제 유튜브에서 Zoro-1과 함께 동작한 기록입니다. 시나리오마다 사람이 읽는 Markdown 파일과 전체 데이터가 담긴 JSON 파일이 하나씩 있습니다.

| 시나리오 | 보여 주는 것 |
| --- | --- |
| `1_3화까지_판정` | 관찰 → Zoro-1 판정 → 애매한 글은 추론 모드로 다시 묻기(라우팅) → 가림/흐림/그대로. 이미 본 회차 내용은 그대로 둠 |
| `2_엔진끊김_자동복구` | 판단 엔진을 끊으면 키워드 방식으로 대신 가리고(작품 이름 제외), 엔진이 살아나면 5초 안에 자동으로 다시 판정 |
| `3_스포신고_기억장학습` | "스포 아님 / 스포였어요" 반응으로 글 종류별 기준 조정, 신고한 사건을 스포 기억장에 추가하고 화면 전체 다시 판정 |

## 로그 읽는 법

- **단계:** 관찰 · 판단 · 라우팅 · 행동 · 학습 · 오류 · 복구
- **확률 / 반영:** Zoro-1이 준 스포 확률과, 이미 본 회차 내용이라 낮춰서(×0.1) 반영한 값
- **기준:** 꼼꼼함 설정과 사용자 반응으로 학습한 보정값을 합친 가림 기준
- 글은 ID로만 남겼습니다. 유튜브 댓글 원문과 닉네임은 레포에 올리지 않습니다.

## 다시 기록하는 법

1. 확장 팝업에서 **에이전트 실행 로그**를 펼치고 **실행 로그 기록**을 켭니다. "글 원문도 남기기"는 끈 채로 둡니다.
2. 시나리오 이름을 쓰고 **새로 시작**을 누릅니다.
3. 유튜브에서 시나리오대로 사용한 뒤 **Markdown**과 **JSON**을 내려받아 이 폴더에 넣습니다.
