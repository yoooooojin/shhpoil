🤫 흑백요리사2를 3화까지 본 사람이 유튜브를 연 상황이에요. 이렇게 해 보세요.
  1. 아래 댓글에서 가려진 글을 찾고 왜?를 눌러 이유를 보세요. 이미 본 3화 얘기는 그대로 보여요.
  2. 오른쪽 다음 동영상에서 스포 제목이 가려진 걸 보고, "최종회 결승전 리뷰"를 보기로 열어 보세요. 영상 자체에 경고가 떠요.
  3. 위의 ＋로 회차를 7 → 13까지 올려 보세요. 가렸던 글이 하나씩 풀리고, 오른쪽 아래 🤫를 누르면 기억장 잠금이 풀려요.
  4. "순댓국 나오는 순간 눈물 났다"에 마우스를 올리거나(휴대폰은 댓글을 눌러) 스포였어요를 누른 뒤 2번 영상으로 가 보세요. 비슷한 글이 같이 가려져요.
  5. 판정을 "키워드 차단"으로 바꿔 기존 방식과 비교해 보세요.
